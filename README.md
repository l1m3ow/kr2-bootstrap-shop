# Тихо — массажная студия на Bootstrap

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».
Практические занятия №9–11. Отдельный проект `kr2-bootstrap-shop`.

Сайт представляет каталог услуг вымышленной массажной студии. Он позволяет выбрать
программу, посмотреть её параметры и заполнить демонстрационную заявку.

## Запуск

Распакуйте проект и откройте `index.html` в браузере. Установка Node.js, npm,
сборка и интернет для работы сайта не нужны. Для разработки можно использовать
VS Code и Live Server. Все пути относительные, поэтому подходят для GitHub Pages.

## Страницы

| Файл | Содержание |
|---|---|
| `index.html` | Первый экран, преимущества, популярные программы, концепция, демо-профили специалистов и FAQ |
| `catalog.html` | Шесть услуг, поиск, фильтр по категории, сортировка, пустая выдача |
| `product.html` | Описание услуги по параметру `service`, характеристики, вкладки, FAQ и переход к записи |
| `order.html` | Выбор услуги, специалиста, даты и времени; контактные поля и динамическая сводка |
| `contacts.html` | Демонстрационные контакты, часы работы и условная схема проезда |

Название `product.html` сохранено из методички; в этой предметной области это страница услуги.
Пример: `product.html?service=feet` показывает «Стопы и голени».

## Технологии

HTML5, Bootstrap **5.3.8**, CSS, JavaScript, локальные WebP/SVG, Git.

Bootstrap подключён **локально**:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

`css/custom.css` подключается после Bootstrap и задаёт палитру, типографику,
размеры изображений и небольшие фирменные дополнения. Основная сетка и компоненты — Bootstrap.
Оригинальные файлы библиотеки скачаны с официального CDN; SHA-384 совпадает с
контрольными суммами официальной документации. Лицензия — `vendor/bootstrap/LICENSE`.

В базовом варианте №9–10 допускается CDN. Локальная поставка выполнена как дополнительное
задание №11 и исключает зависимость готового сайта от доступности CDN.

## Восемь расширений учебного варианта

1. Локальная поставка Bootstrap без CDN и работа без интернета.
2. Дополнительная страница контактов со схемой и графиком.
3. Работающие поиск, фильтрация и сортировка каталога.
4. Шесть описаний услуг через устойчивые идентификаторы и обработка неизвестного идентификатора.
5. Полная форма с датой, временем, выбором специалиста, проверкой телефона и согласия.
6. Динамическая сводка программы, продолжительности, специалиста, времени и стоимости.
7. Accordion с FAQ и вкладки описания и параметров услуги.
8. Проработанная модальная заявка: выбранная услуга передаётся из карточки, проверяется ввод,
   сбрасывается предыдущее состояние, есть переход к полной форме.

Также добавлены адаптивные изображения, единый стиль, стрелка «Наверх», документация и учебная справка.
Это перечень реализованных возможностей. Засчитывание их как самостоятельных доработок зависит
от требований преподавателя и способности автора объяснить код, а не от одного количества пунктов.

## Структура

- `css/custom.css` — фирменное оформление;
- `js/data.js` — демонстрационные услуги и профили специалистов;
- `js/main.js` — поиск, фильтры, подробности, формы и обновление сводки;
- `images/` — локальные иллюстрации, интерьер и схема;
- `vendor/bootstrap/` — Bootstrap и его лицензия;
- `docs/GITHUB_START.md` — создание нового репозитория, ветки, PR и GitHub Pages;
- `docs/STUDY_GUIDE.md` — разбор файлов и ответы на 62 вопроса №9–11;
- `docs/REQUIREMENTS.md` — сопоставление реализации с заданиями;
- `docs/TESTING.md` — выполненные проверки и сценарии для самостоятельного повторения;
- `docs/ASSETS.md` — происхождение иллюстраций.

## Ограничения

Студия, адрес, телефон, цены и специалисты вымышлены. Формы выполняют клиентскую
проверку и показывают итог **демо-заявки**. Они не отправляют данные, не проверяют
свободные места и не бронируют время. Сервер, оплата, аккаунты и постоянное хранение не подключены.
