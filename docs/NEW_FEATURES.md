# Пять новых функций — 12 ноября 2026 года

Эти функции добавлены к уже существующим поиску, фильтрам, сортировке, FAQ, вкладкам,
модальной заявке и карте. Три правки оформления — стрелка, навигация футера и контакты —
в число пяти функций не включены.

|---|---|---|---|
| 1 | Избранные услуги с сохранением | Сердечки на главной, в каталоге и описании; «Только избранное» в каталоге | Появилось состояние выбора, сохраняемое между посещениями, а не только фильтрация текущего списка |
| 2 | Интерактивное сравнение до трёх программ | Кнопки «Сравнить» и нижняя панель | Пользователь сам собирает и меняет набор; таблица строится по выбранным данным, это не фиксированная таблица характеристик |
| 3 | Подбор программы по ответам | «Подобрать программу» на главной, «Помочь с выбором» в каталоге | Три предпочтения преобразуются в рекомендацию с ограничением по времени |

## 1. Избранное

`js/features.js` хранит массивы идентификаторов, например `["relax", "feet"]`.
`localStorage` — встроенное хранилище браузера, сохраняющее значения между посещениями.
Ключ `tiho:favorites:v1` содержит только ID услуг: имена клиентов, телефоны и email туда не записываются.
Перед использованием прочитанные данные проверяются: должны быть массивом, без повторов и неизвестных ID.

Кнопка имеет `data-favorite="feet"` и `aria-pressed`. Последний атрибут сообщает,
включена ли кнопка-переключатель. При изменении выбора обновляются все кнопки и счётчики.
Событие `tiho:favorites-change` просит существующий каталог заново применить условия поиска.

Если браузер запрещает сохранение, выбор продолжает работать в памяти вкладки,
а интерфейс объясняет, что после закрытия он потеряется. Событие `storage` синхронизирует
разные вкладки сайта. Для предсказуемого общего хранилища запускайте сайт через HTTP/HTTPS,
например Live Server или GitHub Pages; поведение `file://` зависит от браузера.

## 2. Сравнение

Набор ID хранится отдельно под ключом `tiho:comparison:v1` и ограничен тремя программами.
Таблица строится из `STUDIO_DATA.services`: название, минуты, цена, формат и интенсивность.
Можно удалить отдельную программу, очистить всё или перейти к записи на выбранную услугу.
Четвёртая программа не добавляется; вместо этого появляется понятное сообщение.

Bootstrap Offcanvas — панель, выезжающая с края экрана. Здесь используется `offcanvas-bottom`.
Её открывает `data-bs-toggle="offcanvas"` с `data-bs-target="#comparePanel"`.
Фреймворк управляет фоном, Escape и фокусом; наш код управляет содержимым сравнения.
На узком экране таблица прокручивается внутри `table-responsive`, а не расширяет страницу.

## 3. Подбор программы

Это опрос о предпочтениях, а не медицинский тест. Сначала из рассмотрения исключаются
программы длиннее выбранного лимита. Затем оставшиеся получают баллы за соответствие
цели и атмосфере. Сортировка выбирает лучший вариант с устойчивым правилом при равенстве.

Пример: «после работы», «до часа» → «Спина и плечи» на 45 минут.
При лимите 30 минут предлагаются «Стопы и голени», а сообщение объясняет ограничение.
При изменении ответа старый результат скрывается, чтобы не показывать устаревшую рекомендацию.
Ссылка на результат передаёт `service=id` в существующую форму записи.

## 4. Подарочная карта

`gifts.html` использует те же хедер, футер и локальный Bootstrap.
`FormData` считывает поля, а `updateGift()` создаёт SVG — векторную разметку изображения.
Один и тот же SVG используется для экрана, скачивания и печати, поэтому результаты совпадают.
Размер текста ограничен; длинные строки переносятся. Пользовательский текст экранируется:
символы `<`, `>`, `&` превращаются в текст, а не исполняемую разметку.

`Blob` — объект с содержимым будущего файла. `URL.createObjectURL()` создаёт временную ссылку,
по которой браузер сохраняет SVG. После скачивания ссылка освобождается.
`window.print()` открывает печать, а `@media print` оставляет только подарочную карту.

Создаётся оформление, а не оплаченный сертификат: продажи, платежей и погашения подарков
в проекте нет. Это явно подписано на странице и в самом файле. Имя и пожелание не сохраняются
в localStorage и никуда не отправляются.

## 5. Файл календаря

Экспорт доступен, когда выбраны услуга и будущие дата/время. Контактные поля для личного
напоминания не нужны. Время рассматривается как московское (UTC+3) и переводится в UTC:
1 декабря 2026 года, 14:00 → `DTSTART:20261201T110000Z`.
Для 30-минутной услуги окончание — `DTEND:20261201T113000Z`.

Формат iCalendar задаёт начало/конец события, уникальный ID, время создания, название и описание.
Файл использует CRLF и перенос длинных строк по 75 байт UTF-8. `STATUS:TENTATIVE`
означает предварительный план, `TRANSP:TRANSPARENT` не помечает это время занятым.
В названии и описании указано, что запись не подтверждена. Импорт в календарь не бронирует
время в студии, не обращается к её серверу и не отправляет приглашения.

## Три запрошенные правки

- Стрелка стала цветком-компасом. Золотое кольцо и процент отражают прокрутку; `requestAnimationFrame`
  ограничивает обновления одним кадром. `ResizeObserver` пересчитывает процент после изменения высоты.
  Основа — обычная ссылка `#top`, работающая и без JavaScript. Учитывается `prefers-reduced-motion`.
- Навигация футера на всех шести страницах повторяет хедер: «Главная», «Услуги», «О процедуре»,
  «Контакты», «Записаться». Менялся только навигационный блок, остальные блоки футера сохранены.
- Контакты макета: `+7 (000) 123-45-67`, `hello@tiho.example`. Это вымышленные значения,
  а не действующие контакты салона; перед реальным использованием их нужно заменить.
  Ссылки используют `tel:` и `mailto:`.

## Какие файлы читать

- `js/features.js` — новые сценарии с отдельными комментариями по пяти функциям.
- `js/main.js` — исходная логика, дополненная связью фильтра с избранным.
- `css/custom.css` — оформление новых блоков, стрелка, адаптивность и печатный режим.
- `gifts.html` — форма и контейнер SVG-предпросмотра.
- Остальные HTML — кнопки, панели и ссылки; все пользовательские скрипты подключаются с `defer`
  в порядке Bootstrap → данные → основной код → новые функции.

Источники: [Bootstrap Offcanvas](https://getbootstrap.com/docs/5.3/components/offcanvas/),
[RFC 5545](https://www.rfc-editor.org/rfc/rfc5545),
[примерные домены IANA](https://www.iana.org/help/example-domains).
