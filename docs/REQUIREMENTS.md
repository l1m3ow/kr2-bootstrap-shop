## Что необходимо сделать владельцу

Удалённый репозиторий создан, исходные файлы загружены; GitHub Pages настроен из main, /(root). После каждого обновления дождитесь успешной публикации, проверьте сайт и отправьте ссылку на репозиторий в СДО. Обновление фотографий, карты и публичных текстов оформлено отдельно от первоначального коммита.

Факт наличия кода не заменяет понимание проекта и защиту работы. Перечень улучшений не гарантирует выставление баллов: итог оценивает преподаватель.
